# InvoiceApi

A powerful **Invoice Management REST API** built with **ASP.NET Core Web API**.

## ✨ Features

- Complete **Invoice CRUD** operations (Create, Read, Print)
- **Product Management** (Full CRUD)
- **JWT-based Authentication & Authorization**
- Secure access — Users can only view and manage **their own invoices**
- Automatic calculation of total invoice amount
- Simple text-based invoice printing
- Built with **Entity Framework Core** and **SQL Server**
- Clean, layered architecture (Controllers, Services, DTOs, Models, Filters)

## 🛠️ Technologies

- **ASP.NET Core** (Web API)
- **Entity Framework Core**
- **SQL Server**
- **JWT (JSON Web Tokens)**
- **C#**

## 📋 Prerequisites

- .NET 5.0 SDK or higher
- SQL Server (LocalDB or full SQL Server)
